# Axel Dima Ganmo — Portfolio Website

Source repository for [aganmo.net](https://aganmo.net), the personal website and professional portfolio of Axel Dima Ganmo.

## Positioning

**Product Engineer · Business Analyst · Venture Architect**

The portfolio brings together product strategy, business analysis, software delivery, and venture development, with a focus on digital products, fintech, payments, and practical technology for organizations.

## Main projects

- **Tontouma Bot** — GovTech assistant for public-service information and orientation.
- **CRM-RYB** — CRM MVP for managing leads, client follow-up, quotes, payments, and business-development workflows.
- **Banking Credit Scoring** — educational machine-learning project exploring credit-risk classification.
- **Bee Colony Insights** — interactive data exploration and visualization with Python and Dash.

## Website stack

The repository is built with Hugo and the Academic/Wowchemy-style site structure, with content and configuration organized in `content/`, `config/`, `static/`, and `assets/`.

## Development

Install Hugo (including the required extended build if needed) and Go, then follow the theme and repository configuration for local development. Review the GitHub Actions and Netlify configuration before changing deployment behavior.
